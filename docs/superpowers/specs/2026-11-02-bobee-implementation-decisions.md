# Implementation decisions

The approved Bobee Link draft remains unchanged. The implementation plan covers desktop controls and Link together, as explicitly delegated on 2026-11-02.

- Use existing tray menus for activity presets Off/5/10/15/30/Always, rest choice, display selection, quiet hours and break reminders. Schema validates any integral activity value 0–60. Keep the existing 10-minute default, sleep at work by default, and retain existing local quiet hours 21:00–07:30 with a saved checkbox. Pause now persists. Saved display ID survives disconnection while the primary display is used temporarily.
- Optional break reminders count only attended PC time (idle below 120 seconds; excludes lock/suspend), independently of Bobee visits and presentations. Presets Off/25/50/60/90 minutes. Notifications offer guidance to use tray snooze (10 active minutes) or skip/reset. No reminders while locked, suspended or idle.
- Snack routine begins after 30 seconds with a jar while Bobee is awake and the PC attended. Three seconds of mopey expression precede a grumpy walk; arrival consumes one real jar treat through the existing jar session and runs munch/happy. A bounded 60-second reservation allows the walk to finish. Manual feeding, dragging, settings changes, unavailable jars, sleep/idle, Pause and Link cancel the routine. No hunger counters or penalties persist. New face strips are drawn in code from the same master poses/palette.
- One sender credential per receiver. The operator's secret enrollment key prevents anonymous receiver creation; it is distinct from short-lived 128-bit pairing codes and per-role 256-bit credentials. Server stores hashes only. Desktop credentials use Windows-backed safeStorage encryption and never enter the companion renderer. The sender browser stores its credential locally; desktop revocation invalidates it.
- Fixed 64×64 RGBA image protocol, 20-second dismissible board, 15-second polling, 10-second request timeout, lock deferral, 100 outstanding server rows and 30-day server retention. See link/README.md for exact semantics, limitations and deployment steps.
- Tests are scoped to root test/**/*.test.js. Prior default Vitest discovery also ran 47 stale suites in archived .claude/worktrees; they are separate checkouts and not regression coverage of this tree.

Review found and tests reproduced sleep-to-home restoration, delayed bubble resizing of boards, and keyboard interruption of snack walking. Each was fixed, with regression coverage. A hidden real Electron renderer check and real local Cloudflare D1 runtime smoke supplement the unit tests.
