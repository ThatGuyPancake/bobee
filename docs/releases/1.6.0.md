## Bobee Link and a little more personality

- Send pixel art from [Bobee Link](https://bobee-link.mihailapatrick.workers.dev) to a securely paired desktop Bobee.
- Bobee announces a special delivery, waits for a click, pulls out the picture frame, and puts it away afterwards. The smaller frame supports reduced motion.
- Drawings queue safely through disconnections and restarts. Deliveries interrupt Pause, Go home, quiet hours and the hourly activity budget, then restore the current settings.
- The website confirms when the picture is received by Bobee and when he has finished displaying it.
- Choose active minutes per hour, Go home or Sleep at work, your preferred monitor, quiet hours and optional break reminders with snooze/skip. Settings and Pause are saved.
- Leave a treat jar beside an awake Bobee and he briefly gets mopey, fetches himself a snack, then perks up. No hunger penalties build up while you are away.

### Updating

Existing happiness, settings and Link pairing are preserved. On installed Bobee 1.5.0, choose **Check for updates** from the tray, then **Update 1.6.0 ready — restart Bobee** when the download finishes. You can also run **Bobee-Setup-1.6.0.exe** directly.

For Link setup, open **Bobee Link…** in the desktop tray. The enrollment key belongs in the desktop settings; the short-lived pairing code generated there belongs on the website. See [the setup guide](https://github.com/ThatGuyPancake/bobee/blob/v1.6.0/link/README.md).

The receiver must be running and connected to download queued drawings; locked or suspended PCs defer their presentation.
